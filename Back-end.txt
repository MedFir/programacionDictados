Node.js
Es un entorno de ejecucion de JS del lado del servidor, esto significa que permite ejecutar codigo JS fuera de un navegador web, directamente en una computadora o servidor. Esta construido sobre el motor de JS v8 de chrome, lo que le da un alto rendimiento y velocidad.
Node.js utiliza un modelo de entrada / salida asyncrono y orientado a eventos. En lugar de esperar a que una operacion termine antes de pasar a la siguiente, node puede iniciar varias operaciones al mismo tiempo y manejar las respuestas a medida que llegan. Es crucial que sea orientado a eventos para escuchar y ejecutar la logica necesaria para responder las solicitudes.

Modulos fundamentales de node.js
-FS (File System):
Permite interactuar con el sistema de archivos de la computadora. Se puede usar para leer, escribir, modificar o eliminar archivos y directorios. Contiene las funciones 'fs.readFile()', 'fs.weiteFile()', 'fs.mkdir()', 'fs.unlink()', entre otras.

-Path:
Proporciona utilidades para trabajar con rutas de archivos y directorios de manera que funcione igual para todos los sistemas operativos (windows, macOS, linux). Cuenta con las funcionalidades 'path.join()', 'path.resolve()', 'path.extname()'

-HTTP Y HTTPS
Son los modulos claves para crear servidores web y realizar peticiones a otros servidores. HTTPS es la version segura que utiliza ssl / tls. Se usa para crear un servidor con 'http.createServer();', hacer peticiones a apis con 'http.request()' o 'http.get()'.

-OS (Operating System)
Brinda informacion y utilidades relacionadas con el SO en el que se esta ejecutando el proyecto. Algunas de sus funcionalidades son 'os.cpus()', 'os.totalmem()', 'os.freemem', 'os.homedir()' y 'os.plataform()'.

-Crypto
Ofrece funcionalidades cryptograficas para realizar tareas de seguridad, como encriptar y desencriptar datos, crear hashes y firmar informacion digitalmente.


Proyeto basico
Para poner en practica el uso de node.js se puede crear un proyecto basico donde se muestre mensajes en la consola:
1- Crear un nuevo archivo enla carpeta del proyecto llamado 'index.js'.
2- Para proyectos reales se deberia inicializar y crear el archivo 'package.json' con el comando npm init.
3- Escribir el siguiente codigo dentro del archivo '.js':
...
const prueba = "ejemplo de constante";
console.log("Primer proyecto");
console.log(prueba);
...
4- Abrir la consola o terminal donde se creo el archivo y ejecutar el siguiente comando:
'node index.js'
5- Al ejecutarlo, node.js procesara el archivo y mostrara los mensajes en la misma consola  termianal.

Variables de entorno
Son valores externos a la app que se utilizan para configurar su comportamiento sin modificar el codigo fuente. Son fundamentales por 2 razones principales:
1- Seguridad: permite ocultar datos sensibles como contraseñas de BDD, claves de api, o token.secret de JWT, evitando que se suban a repositorios publicos.
2- Flexibilidad: facilitan el cambio de configuracion, por ejemplo para cambiar al puerto de escucha del servidor http sin cambiar el codigo.

En node.js estas variables almacenan comunmente en un archivo llamado .env y se acceden en el codigo mediante el objeto global process.env.

Implementacion de variables de entorno con dotenv
Para utilizar archivos dotenv en archivos y utiizar sus variables en un proyecto, se puede utilizar la libreria dotenv de la siguiente manera:
1- Instalar la dependencia: con 'npm install dotenv'.
2- Crear el archivo.env en la raiz del proyecto, con sus variables, por ejemplo:
...
PORT = 3000
DB_PASS = Ejemplo124
TOKEN_SECRET = "clave_123"
...
3- Uso en el codigo de JS
## index.js ##
...
require("dotenv").config();
const port = process.env.PORT || 4000;
const db_pass = process.env.DB_PASS;
const {token_secret} = process.env;
...

Es importante recordar que el archivo .env nunca se debe subir a los repositorios, por esto debe agregarse en el archivo .gitignore

Metodos de API
Express.js facilita la definicion de rutas para diferentes metodos HTTP.
-GET
Para recuperar datos

-POST
Para enviar datos y crear nuevos registros

-PUT
Para actualizar registros existentes

-DELETE 
Para eliminar registros

-Ejecutar codigo
-Realizar cambios en los objetos de solicitud y respuesta
-Terminar el ciclo de la solicitud

Router en express.js
En express.js, un router es escensialmente una mini app que se puede usar para agrupar rutas relacionadas y middlewars. Actua como un sistema modular para organizar las rutas, haciendolas mas limpias y faciles de mantener, especialmente en aplicaciones grandes.

...

router.get("/", function(req,res,next){
	//recurso normal
});
module.exports = router;

//index.js
require ("dotenv").config();
const express = require("express");
const usuariosRouter = require(:/usuarios.js");
const {PORT} = process.env;
const app = express ();
app.use("/usuarios",usuariosRouter);
app.get("/", function(req,res,next){
	//recurso normal
});
app.listen(PORT,function(error){
	if (error) {
		console.error(error);
		process.exit(1);
	}
